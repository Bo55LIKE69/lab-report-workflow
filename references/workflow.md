# 七阶段详细规程（workflow.md)

> 本文件是 `SKILL.md` 分步清单的展开版。改流程只改这里。

## 阶段0 参数收集

**输入**：用户一句话需求（主题+数据路径+其他已知信息）

**动作**：
1. 对照 SKILL.md 占位符表逐项过一遍，能推断的给出推断值，不能的列为"待补充"
2. 向用户输出参数确认块（下方格式），等用户回复（此处即 CP1 前置，可与 CP1 合并提问）

```
【参数确认】
实验名称：{{EXPERIMENT_NAME}}
课程/教师：{{COURSE_TEACHER}}（待补充则注明）
实验日期：{{EXP_DATE}}
数据文件：{{DATA_PATHS}}
篇幅要求：{{LENGTH_REQ}}
评分标准：{{GRADING_RUBRIC}}
模板文件：{{TEMPLATE_PATH}}（无 → 用内置骨架）
软件环境：{{SOFTWARE_ENV}}
```

**输出**：参数确认块 + "待确认清单"初版

**校验**：无 `{{DATA_PATHS}}` 且用户明确"只要框架"→ 记录为无数据模式，报告所有数据位置用 `【待补充：原始数据】` 标注

---

## 阶段1 实验预习（目的、原理、器材、步骤）

**输入**：实验主题、教材/讲义/实验指导书内容、用户口述要求

**动作**：
1. **实验目的**：3–5 条，动词开头（掌握/熟悉/验证/测定/学会），与后续步骤一一呼应
2. **实验原理**：
   - 核心公式逐条编号（式1、式2…），每个符号给出含义与单位
   - 写明公式适用条件与假设（如"忽略空气阻力""假设各因子相互独立"）
   - 原理图（若有）配图题
3. **实验器材**：硬件（型号）、软件（名称+版本）、数据（名称+来源+分辨率/精度/坐标系等元信息）
4. **实验步骤**：编号写法，每步可复现——工具/方法名 + 关键参数 + 预期中间产物；避免"点击这里选那个"的 GUI 白描，写成"用 XX 方法，参数设为 YY，得到 ZZ"

**输出**：预习四节初稿

**校验**：
- [ ] 每条目的能指出由哪个步骤实现
- [ ] 公式有编号、符号有表、条件有说明
- [ ] 步骤能脱离本报告独立复现
- [ ] 教材/讲义原句未直接照抄（防抄袭判定），改写并保留技术准确性

---

## 阶段2 原始数据记录

**输入**：`{{DATA_PATHS}}`（CSV/Excel/栅格/矢量/照片等）

**动作**：
1. 逐文件读取，记录：文件名、格式、行数/像元数、字段/波段、单位、量纲、坐标系或基准、时间范围
2. 生成"数据概况表"（一张表汇总全部数据源）
3. 标注缺失值、异常值、重复值（只标注，**不修改原始文件**）
4. 数据照片/截图：记录拍摄参数或截图范围，作为附录素材

**输出**：原始数据记录表 + 数据概况说明段

**校验**：
- [ ] 概况表数字与源文件一致（行数、字段数逐项核对）
- [ ] 未在原始文件上做任何写操作
- [ ] 每个数据源都注明来源（自己测的/老师发的/公开数据集+网址）

> **→ CP1 检查点**：把数据盘点结果和处理方案汇报给用户，确认后才进入阶段3

---

## 阶段3 数据处理与计算（含误差分析、有效数字与单位）

**输入**：阶段2确认后的数据

**动作**：
1. 按阶段1公式逐步计算，**保留中间量**（写成中间结果表，便于复算与排错）
2. 误差分析（按实验类型选其一或组合）：
   - 测量类：绝对误差 Δx、相对误差 δ、标准差/不确定度
   - 模型类：RMSE / MAE / R²，训练-验证划分说明
   - 分类/制图类：混淆矩阵、总体精度、Kappa
3. 有效数字：运算结果位数 ≤ 原始数据最低精度；中间量多保留 1–2 位，最终结果按约定修约
4. 单位：全文统一国际单位制或课程惯用单位；换算处显式写出换算因子

**输出**：处理结果表（含中间量列）、误差分析小节

**校验**：
- [ ] 单位量纲自洽（代入检查一个算例）
- [ ] 有效数字位数与数据精度匹配，无"精度虚高"
- [ ] 抽一个数据点手工/脚本复算，结果一致
- [ ] 误差分析有数据支撑，不是套话

> **→ CP2 检查点**：汇报公式选择、误差模型、有效数字约定
> **→ CP3 检查点**：中间结果摘要数字过目后，才进阶段4/5

---

## 阶段4 图表绘制与结果呈现

**输入**：处理结果表

**动作**：
1. 按数据形态选图型：
   - 数据点关系 → 散点图（含拟合线+方程+R²）
   - 分布 → 直方图/箱线图
   - 趋势 → 折线图
   - 分类对比 → 柱状图
   - 空间数据 → 专题地图（含指北针、比例尺、图例、坐标系说明）
2. 图表规范：轴名+单位必标；图例不遮挡数据；配色考虑打印黑白可辨
3. 编号与引用：图1、图2…表1、表2…全文连续；正文每处必须出现"如图N所示/见表N"
4. 图题在**图下方**，表题在**表上方**（国标惯例）

**输出**：图表文件（PNG，≥300dpi）+ 正文引用句

**校验**：
- [ ] 无孤儿图/表（每张都被正文引用）
- [ ] 编号连续无跳号
- [ ] 轴、单位、图例齐全，脱离正文也能看懂

---

## 阶段5 结果讨论

**输入**：阶段3–4 全部产物

**动作**：
1. 结果解释：数据/图说明了什么，与预期是否一致
2. 对比：与理论值、文献值、老师给定参考值对比，算偏差并讨论显著性
3. 误差来源归类：系统性 / 随机性 / 过失性，每类落到**本实验的具体现象**上（如"图3中异常高值来自第17组样品的称量滞后"）
4. 改进建议：针对主要误差来源给可操作改进，不写"更认真操作"式空话

**输出**：讨论章节

**校验**：
- [ ] 每个误差来源对应具体数据现象
- [ ] 对比引用了具体数值，而非"基本吻合"一笔带过
- [ ] 改进建议可执行

---

## 阶段6 结论

**输入**：全篇

**动作**：写 3–5 条结论：直接回答实验目的；关键结果给出"数值 ± 不确定度（单位）"；用完成时/陈述句，不加主观感叹

**输出**：结论章节

**校验**：
- [ ] 逐条对照实验目的，无遗漏
- [ ] 未引入讨论中没出现的新数据/新结论
- [ ] 数值与阶段3结果表完全一致（防止多处数字漂移）

> **→ CP4 检查点**：结论草稿交用户过目

---

## 阶段7 排版交付（封面、目录、参考文献、模板要求）

**输入**：全文 + `{{TEMPLATE_PATH}}`

**动作**：
1. 有模板：解包模板样式（标题层级、字体字号、页边距、页眉页脚、封面字段），逐项套用
2. 无模板：用 `templates/report_template.md` 骨架，默认：标题黑体三号居中、一级标题黑体四号、正文宋体小四 1.5 倍行距、页码居中——并在交付时声明"这是通用规范，可按学校要求调整"
3. 目录：标题必须挂真实大纲级别（outlineLvl / 标题样式）后自动生成，禁止手打目录
4. 参考文献：GB/T 7714 格式；只列实际引用的文献，**没有查证过的文献一律不写**
5. 产出 docx：改前备份 → 写入 → 跑自查清单 → 交付

**输出**：可提交的 docx + 备份文件

**校验**：跑完 `references/checklist.md` 全部条目

> **→ CP5 检查点**：汇报自查结果与遗留"待确认清单"，用户确认后收尾
