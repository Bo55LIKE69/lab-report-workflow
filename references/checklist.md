# 常见错误自查清单（checklist.md）

> 阶段7 交付前逐条过一遍。任何一条不过，先修复再交付。踩到新坑就往对应分区补一条。

## 数据类

- [ ] 报告中所有数值与源数据/处理结果表一致，无手工转录错误（抽 3 个数核对）
- [ ] 无编造数据：缺的都标了 `【待补充】`，而不是填了"合理"的假数
- [ ] 原始数据文件未被修改（改动只发生在副本/输出文件）
- [ ] 缺失值、异常值的处理方式在正文有交代
- [ ] 同一物理量在全文（表、图、正文）中的数值和单位完全一致

## 计算类

- [ ] 至少抽 1 个数据点复算通过
- [ ] 有效数字位数合理（无精度虚高）
- [ ] 单位量纲自洽；换算处有显式因子
- [ ] 误差分析引用了具体数字，误差来源对应具体现象

## 图表类

- [ ] 无孤儿图/表：每张都被"如图N/表N所示"引用
- [ ] 图表编号全文连续、无跳号、无重号
- [ ] 图题在图下、表题在表上；轴名+单位齐全
- [ ] 截图清晰可辨参数值；题注格式统一（图N 说明，居中）

## 结构类

- [ ] 实验目的的每一条都能在步骤/结论中找到对应
- [ ] 结论未引入讨论中不存在的新数据/新观点
- [ ] 结论逐条回答了实验目的
- [ ] 讨论有对比（理论值/文献值）且有偏差数字

## 文献类

- [ ] 参考文献只列实际引用且查证过的
- [ ] 格式符合 GB/T 7714（[M]/[J]/[D]/[R]/[EB/OL] 标注正确）
- [ ] 正文引用处有编号对应

## 排版类（docx）

- [ ] 封面字段齐全：姓名/学号/班级/教师/日期与实际一致（这是最容易抄错上一个实验的地方）
- [ ] 目录由标题大纲级别自动生成（标题挂了 outlineLvl 或标题样式），非手打
- [ ] 正文段没有残留大纲级别（不会混进导航窗格）
- [ ] 页眉页脚、页码符合模板要求
- [ ] 字体字号符合模板：标题层级分明、正文统一
- [ ] 图片题注居中且编号连续；封面装饰图未编号
- [ ] 交付前已做备份文件（`*_操作前备份.docx`）
- [ ] 全文搜索"待补充/【待确认/TODO/占位"，确保无残留

## 交付类

- [ ] 交付物：最终 docx + 备份 + （如有）图表源文件
- [ ] 向用户说明：哪些部分是推断/默认值、遗留的"待确认清单"有哪些
- [ ] 参数、公式、工具路径、字段名在文字润色中未被误改
