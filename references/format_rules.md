# 数据处理与图表规范（format_rules.md）

## 1. 有效数字

- 运算结果的有效位数 ≤ 原始数据中精度最低的那个数
- 中间量多保留 1–2 位防累积舍入误差，**只在最终结果处修约**
- 修约规则：四舍六入五成双（GB/T 8170），不连续"四舍五入"
- 常见错误：用计算器全位数照抄（如 3.14159265 抄进报告）；0.5 与 0.50 混用（精度声明不同）

## 2. 单位与量纲

- 优先国际单位制（SI）；课程有惯例（如 mg/kg、mm/a）则全文统一该惯例
- 单位符号正体、与数值间留空（25.3 mm）；中文语境"每"用斜杠不用"的"
- 换算显式写因子：`1 ha = 10⁴ m²`，不默换
- 量纲自洽检查法：代入一组真实数据手算一遍，单位能约成目标单位才放行

## 3. 误差分析选型

| 实验类型 | 推荐指标 |
|---|---|
| 物理测量 | 绝对误差 Δx、相对误差 δ、不确定度 u（A类/B类） |
| 回归/反演模型 | RMSE、MAE、R²、Bias；写明训练/验证划分 |
| 分类/制图 | 混淆矩阵、总体精度 OA、Kappa、用户/生产者精度 |
| 重复测量 | 标准差、变异系数 CV |

写法要求：每个指标落到具体数字；误差来源按**系统性 / 随机性 / 过失性**归类，且各对应一个数据中的具体现象。

## 4. 图表规范

### 图
- 选型：点关系→散点；分布→直方/箱线；趋势→折线；组成对比→柱状/饼（≤5 类才用饼）；空间数据→专题地图（指北针+比例尺+图例+坐标系说明）
- 必备元素：轴名+单位、图例、数据来源说明（如需）
- 分辨率 ≥300 dpi（PNG/TIFF），矢量图优先（PDF/SVG）
- 黑白打印可辨：用线型/填充图案区分，不只靠颜色
- 图题在图**下方**："图N {{说明}}"，居中
- 每张图必须被正文"如图N所示"引用，编号全文连续

### 表
- 表题在表**上方**："表N {{说明}}"，居中
- 三线表（顶线、栏目线、底线），不画全框网格
- 表内数值有效位数一致；空缺用"—"不用留白
- 每张表必须被正文"见表N"引用

### 截图类（软件操作实验，如 ArcGIS Pro）
- 工具参数设置图与结果图分开设图注："XX工具参数设置" vs "XX结果"
- 截图清晰度足够辨认参数值；全屏截图前清理无关窗口内容
- 题注编号全文连续；封面/装饰图不编号

## 5. 防抄袭与学术规范

- 教材/讲义原理部分改写复述，不整段照抄；引用处标注文献编号
- 数据只有自己实验的真实值；引用文献值必须标来源
- 参考文献 GB/T 7714：专著[M]、期刊[J]、学位论文[D]、报告[R]、电子资源[EB/OL]（含引用日期）
- 查证不到的文献一律不列——宁可少一条，不可编一条
